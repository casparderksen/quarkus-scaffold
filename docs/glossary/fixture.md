# Fixture

A fixture is a predefined set of test data or an object graph that a test
starts from.

## Why

Many tests need the system in a known starting state before they can exercise
anything. A fixture establishes that state consistently, so tests begin from
solid, repeatable ground rather than each assembling its world from scratch.
