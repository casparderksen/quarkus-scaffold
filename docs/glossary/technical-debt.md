# Technical Debt

Technical debt is the long-term cost incurred by short-term implementation
compromises — the interest paid later for expedient choices made now.

## Why it matters

Like financial debt, a little can be a sensible trade to ship sooner, but left
unpaid it compounds: each shortcut makes the next change slower and riskier
until progress stalls. Naming it makes the trade-off explicit and the repayment
a deliberate decision rather than a surprise.
