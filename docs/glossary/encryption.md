# Encryption

Encryption transforms plaintext into ciphertext so that only a party holding
the right key can recover the original.

## Why

It protects confidentiality — of data in transit and at rest — against anyone
who can see the bytes but lacks the key. Symmetric schemes use one shared
key; asymmetric schemes use a public/private key pair, which also underpins
digital signatures and certificates.
