# HTTP

HTTP is the request/response transport protocol underlying the web and most
web APIs.

## Why

Its verbs, status codes, and headers give a common, universally supported
vocabulary for exchanging data over the network. Higher-level styles such as
REST and protocols such as SOAP are built on top of it, which is why an
understanding of its semantics underpins most web integration.
