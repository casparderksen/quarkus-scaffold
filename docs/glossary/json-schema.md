# JSON Schema

JSON Schema is a format for describing the structure of JSON data so that it
can be validated automatically.

## Why

A schema states what a valid document looks like — which fields are required,
what types they hold, what values are allowed — so that data can be checked
against it mechanically rather than by hand-written, error-prone conditionals.
Both OpenAPI and AsyncAPI build on it to describe their payloads.
