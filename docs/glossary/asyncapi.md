# AsyncAPI

AsyncAPI is a standard format for describing asynchronous, message-based APIs
— the channels, messages, and schemas of an event-driven system.

## Why

It brings to messaging what OpenAPI brings to HTTP: a formal, machine-readable
contract that can document channels, validate messages, and generate code, so
that event-driven integrations are described as rigorously as request/response
ones.
