# Zero Trust

Zero trust is a security model that assumes no implicit trust between
components, requiring every request to be authenticated and authorized
regardless of where it originates.

## Why

The traditional model trusted anything inside the network perimeter, so a
single breach of the perimeter exposed everything behind it. Zero trust drops
that assumption: internal and external requests are treated alike and must
each prove themselves, which contains the damage when any one boundary is
breached.
