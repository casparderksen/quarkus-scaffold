# OpenAPI Validation

OpenAPI validation is the verification that an API's actual behavior matches
its OpenAPI specification.

## Why

A specification is only trustworthy if the implementation truly conforms to
it. Validating requests and responses against the spec catches drift between
the documented contract and the running service, so consumers can rely on the
document.
