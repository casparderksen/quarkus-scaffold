# Outbound Adapter

An outbound adapter, also called a driven adapter, implements an outbound
port to reach a concrete external system on the application's behalf.

## Examples

A storage adapter that persists aggregates, a producer that publishes
messages, a client that calls another service, or a cache implementation —
each fulfils a need the core expressed as a port.
