# JSON

JSON is a lightweight, text-based data-interchange format built from
name/value pairs and ordered lists.

## Why

It is simple to read, simple to generate, and supported everywhere, which has
made it the default payload format for web APIs and messaging. Its structure
can be described and validated with JSON Schema.

## Contrast

[XML](xml.md) is more verbose and markup-oriented; JSON is terser and maps
directly onto common data structures.
