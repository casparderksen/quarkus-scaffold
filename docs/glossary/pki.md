# PKI (Public Key Infrastructure)

Public key infrastructure is the system of authorities, certificates, and
policies that manages digital certificates and the public keys they bind.

## Why

Public-key cryptography only helps if you can trust that a given public key
really belongs to whom it claims. PKI provides that trust through certificate
authorities that vouch for keys and mechanisms to issue, distribute, and
revoke the resulting certificates.
