# Upstream / Downstream Context

Upstream and downstream describe the direction of influence between two
integrated contexts: the upstream context supplies, the downstream context
depends.

## Why

Naming the direction clarifies who sets the terms of the relationship.
Changes originate upstream and flow down; the downstream context absorbs
them, so it must decide how much of the upstream model it is willing to let
in.
