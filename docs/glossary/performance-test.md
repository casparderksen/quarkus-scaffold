# Performance Test

A performance test measures a system's runtime characteristics — throughput,
latency, behavior under concurrency, and endurance over time.

## Why

Correctness under light load says nothing about behavior under real load. A
performance test quantifies how the system responds as demand rises and
sustains, surfacing bottlenecks, resource leaks, and degradation before users
encounter them.
