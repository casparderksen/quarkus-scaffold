# SOAP

SOAP is a standardized, XML-based messaging protocol, common in older
enterprise systems.

## Why

It defines a rigid envelope and a rich set of standards for concerns like
security and transactions, which suited formal enterprise integration.
Compared with REST it is heavier and more ceremonious, which is why newer
systems usually favor lighter styles, though SOAP endpoints persist where
legacy systems must be integrated.
