# Ubiquitous Language

The ubiquitous language is the shared vocabulary of a bounded context, used
consistently by domain experts and developers and reflected directly in the
code.

## Why

When the names in the model match the words people say in conversation,
there is no hidden translation step to get wrong. A concept discussed in a
meeting appears under the same name in the code, so discussions and
implementation stay in sync.
