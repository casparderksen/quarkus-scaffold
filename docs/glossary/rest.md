# REST

REST is a style for web APIs that models a system as resources, addressed by
URLs and manipulated through a small, uniform set of HTTP operations.

## Why

By reusing HTTP's own verbs and status codes and treating everything as an
addressable resource, REST gives APIs a predictable, widely understood shape
that needs little bespoke convention. Its uniformity is what makes generic
tooling, caching, and documentation possible.
