# Generator

A generator is a component that produces randomized or fuzzed test data.

## Why

Hand-picked examples test only the cases a developer thought of. A generator
produces many varied inputs, including odd ones a person would not choose,
which is what lets property-based testing probe an invariant across a wide
space of values rather than a handful.
