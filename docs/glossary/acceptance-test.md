# Acceptance Test

An acceptance test validates that the system meets a business requirement,
framed from the stakeholder's point of view.

## Why

Passing technical tests does not prove the system does what the business
asked. An acceptance test expresses the requirement in the stakeholder's
terms and checks the system against it, so "it works" means "it does what was
wanted."
