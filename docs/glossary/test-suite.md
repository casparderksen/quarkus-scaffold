# Test Suite

A test suite is a collection of related tests grouped to be run together.

## Why

Grouping tests lets them be organized, selected, and executed as a unit — all
the tests for a module, or a fast subset to run on every change. The suite is
the handle by which a body of tests is managed and reported on.
