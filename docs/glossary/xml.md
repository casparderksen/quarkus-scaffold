# XML

XML is a markup-based data-interchange format that represents data as nested,
tagged elements.

## Why

Its tag structure, namespaces, and schema languages make it expressive and
strict, which suited formal document exchange and enterprise standards such as
SOAP. That same verbosity is why lighter formats like JSON have largely
displaced it for new web APIs.

## Contrast

[JSON](json.md) is terser and maps directly onto common data structures; XML
is more verbose but more expressive for document markup.
