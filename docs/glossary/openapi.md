# OpenAPI

OpenAPI is a standard format for describing the shape of an HTTP API — its
endpoints, parameters, and request and response schemas — in a
machine-readable document.

## Why

A single formal description serves several purposes at once: it documents the
API for humans, drives validation that an implementation matches the
contract, and can generate client or server code so the contract and the code
stay aligned.
