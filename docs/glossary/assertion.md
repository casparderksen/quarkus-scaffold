# Assertion

An assertion is a statement within a test that verifies an expected result or
state, failing the test when it does not hold.

## Why

An assertion is where a test actually checks something. Without one, code
merely runs; with one, the test declares what must be true and fails loudly
when reality disagrees. Clear, specific assertions are what make a failure
diagnosable.
