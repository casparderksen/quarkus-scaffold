# Published Language

A published language is the well-documented, deliberately exposed contract a
context offers for integration — the vocabulary outsiders are meant to
depend on.

## Why

Consumers should couple to a stable, intentional contract, not to a
context's internal domain types, which are free to change. Publishing a
language draws a clear line between what is promised to the outside and what
remains private.

## Example

The capability contracts a context exposes for others to call, and the
versioned events it publishes for others to consume.
