# Fixture File

A fixture file is a static resource — a sample payload, a data script, a
schema — kept on disk and loaded by tests.

## Why

Keeping bulky or reusable test inputs in files, rather than inline in test
code, keeps the tests readable and lets the same input serve several tests. A
representative sample payload or dataset lives in one place and is loaded
where needed.
