# Private Key / Public Key

A private and public key form an asymmetric key pair: the private key is kept
secret and used to sign or decrypt, while the public key is shared and used to
verify or encrypt.

## Why

Because the two keys are mathematically linked but not derivable from each
other, a holder can prove possession of the private key, or receive data only
they can read, without ever sharing the secret. This asymmetry underlies
signatures, certificates, and much of secure communication.
