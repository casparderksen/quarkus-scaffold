# Context Map

A context map is a high-level picture of how bounded contexts relate to one
another — who integrates with whom, in which direction, and by what pattern.

## Why

It makes the relationships between contexts explicit: which context supplies
and which depends, where translation happens, and which integration pattern
governs each link. Without such a map, these relationships exist only
implicitly and drift without anyone noticing.
