# Smoke Test

A smoke test is a lightweight check that a deployed system starts up and its
most basic flow works.

## Why

After a deployment, the first question is simply whether the thing is alive
and fundamentally functional. A quick smoke test answers that immediately, so
an obviously broken release is caught before deeper testing or real traffic
reaches it.
